## Discussion

### Discuss Readings:

**ScPerturBench**: Let's discuss the metrics they use:
- They state in the paper that they focus on population average metrics instead of population distribution metrics, we should focus on **both**
  - population average example: MSE, population distribution example: JS divergence, KL divergence

Other really important metrics for us to observe model performace are: \
- Metric miLISI: Map to a lower dimensional space and see if they are discernable, cellPACE, GroungGAN, ...
- Common DEGs: Case vs control - A statistical test on both distributions, Mann-whitney u test. 

- Q: ScPerturBench benchmarks against linear models, should we do the same?
- A: Yes! We should test 3 main categories of models: Naive baselines (no change, mean across all genes), off-the-shelf methods (simple MLP, ...), SOTA methods (proposed newer methods)
  
**Benchmarking Pretrained Molecular Embedding Models for Molecular Representation Learning**:
- They state that 1 model, CLAMP consistently outperforms fingerprint ECFP
- Otherwise, there are 4 other models that are on par with fingerprints, how should we decide which and how many to use?
- We want a mix of models that are strong, have different architectures. These were suggested:

- Drug Embedding models:
1. CLAMP
2. ChemBERTa
3. Morgan Fingerprints
4. MAP embeddings (if we can extract them easily)
5. constant input / no drug (see if there are real effects of these drug inputs maybe)


### Project Scope


- Dimensionality for benchmarking papers: 12 models (8 SOTA, 2 off-shelf, 2 naive )x (4 embeddings + 1 fingerprint) x 1 dataset x N cell lines (ideally)
  - We will only use the TAHOE dataset, but our goal should be develop a code base that is generic to cell line. 
  - That way, we can have 12 models x 5 embeddings x 1 dataset x N cell lines = 60 x N experiments in total. 
  - If we can develop a sound pipeline, then expanding to other cell lines should be very straight forward
    - They will reproduce all of the same figures, metrics, ..., we should just have to toggle the dataset input
